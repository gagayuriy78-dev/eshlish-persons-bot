ASOSIY TEKSHIRUV:

- API server haqiqatan Replit Secrets'dagi YANGI bot tokenni olayaptimi?
- `TEST_TOKEN` secret mavjudmi?
- `main.py` va API server bir xil YANGI bot tokenidan foydalanayaptimi?
- Telegram Mini App `window.Telegram.WebApp.initData` ni olayaptimi?
- Frontend `X-Telegram-Init-Data` header orqali initData'ni API serverga yuboryaptimi?
- Backend shu initData'ni aynan yangi bot token bilan HMAC orqali tekshirayaptimi?
- `auth_date` tekshiruvi to‘g‘ri ishlayaptimi?
- Noto‘g‘ri token sabab `bad signature` bo‘lib, frontendda noto‘g‘ri ravishda "authorization expired" xabari ko‘rsatilmayaptimi?

JUDA MUHIM:
Hozir `AUTH_MAX_AGE_SECONDS = 24 * 60 * 60`.

Buni shunchaki o‘chirib tashlama va authorization xavfsizligini pasaytirma.

Agar `auth_date` haqiqatan eski bo‘lsa, Telegram yangi Mini App ochilganda yangi initData berishini hisobga olib flow'ni to‘g‘ri tuzat.

Yana bir muhim muammo:
`middlewares/auth.ts` ichida `bad signature` va `expired` ikkalasi ham frontendga bir xil umumiy authorization xatosi sifatida qaytmoqda.

Debug qilish uchun server logiga:
- `authFailure` sababini
- request path
- tokenning o‘zini EMAS

chiqaradigan xavfsiz diagnostika qo‘sh.
